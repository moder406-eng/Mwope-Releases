## 📖 About The Project

**Mwope** is not just a messenger. It's an ecosystem built by a Creator for Creators. It features its own economy, custom bots, voice messages, groups, channels, and a unique reward system for activity.

This repository is dedicated solely to **distributing updates** (Releases) for the Mwope client. Here you will find the latest installer versions, which are automatically pulled through the built-in auto-updater.

---

## 📥 How to Install?

Installing Mwope is incredibly simple:

1. Go to the **[Releases](https://github.com/moder406-eng/Mwope-Releases/releases)** section (on the right side of this page).
2. Find the latest version (e.g., `v0.0.1` or `v0.0.2`).
3. Download the **`Mwope Setup X.X.X.exe`** file.
4. Run the installer and follow the on-screen instructions.
5. After installation, launch **Mwope** from your desktop and log into your account!

> 💡 **Important:** If you already have an older version of Mwope installed, you **do not** need to download the new installer manually. The app will automatically detect the update, download it in the background, and prompt you to restart!

## ✨ Key Features (What's Inside?)

*   💬 **Messenger:** Direct messages, groups, and channels with WebSockets support (instant message delivery).
*   🪶 **Feather Economy:** Send messages, earn Feathers, and spend them on invisibility (`/ghost`) and other perks.
*   🤖 **System Bot:** The `System` bot keeps things in order, gives out rewards, and supports commands (like `/ann` for announcements).
*   📞 **Voice & Files:** Send voice messages and files of any size directly in the chat.
*   🎨 **Customization:** Light and dark theme support, pinned messages, reactions, and much more.
*   🛡️ **Security:** Passwords are hashed (SHA-256), and the Creator has secret access.

## 🛠️ For Developers (Tech Stack)

Mwope is built with a love for clean code and optimization:

*   **Client:** Electron.js, HTML5, CSS3, Vanilla JavaScript.
*   **Server:** Python 3, FastAPI, WebSockets, SQLite.
*   **Infrastructure:** VPS (France), GitHub Releases (for auto-updates).
